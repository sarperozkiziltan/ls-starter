# Session Log

Running record of what is built in this Lens and why, kept across sessions.
Newest entry first. See the "Session Log" section of `CLAUDE.md` for how this file is maintained.

This file ships empty with the template and stays empty here — work on the template itself is not
logged. Entries start once this repository has been copied to build an actual Lens.

Entry skeleton:

```markdown
## YYYY-MM-DD

### Work done

### Decisions

### Scene setup

### In progress
```
